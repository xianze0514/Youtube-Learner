# English Listening Typing

一个完全本地运行的 Chrome 扩展，用 YouTube 原声和字幕进行逐句听写打字训练。

## 功能流程

1. 点击浏览器工具栏中的扩展按钮。
2. 扩展读取当前 YouTube 视频的字幕，并进入全屏训练页面。
3. 扩展会优先使用人工英文字幕作为听写文本，保证句子和标点尽可能准确；如果同时存在自动英文字幕，则读取其中的逐词时间戳并与人工字幕对齐。
4. 字幕会先消除滚动字幕的重叠词，再结合句末标点、语法连续性、大小写和停顿长度还原完整句子；不会再按固定的 10 秒或 130 字把长句从中间截断，也不会跨越明显停顿拼接无关片段。
5. 对齐成功后，上一句会在下一句首词开始前停止，下一句从该词前少量预滚开始；没有逐词时间的句子才使用带安全重叠的估算边界。
6. `(Laughter)`、`[Music]`、`(Applause)` 等声音或舞台提示会自动移除，不要求用户输入；同一条字幕中的真实对白会保留。
7. 直接使用键盘填写视频下方的字符横线，不需要点击输入框。
8. 正确字符会保留并变绿；当前单词输错后会变红、抖动并清空该单词，前面的正确单词不受影响。
9. 大小写不敏感，标点自动跳过，空格需要输入。
10. 输入正确后自动重播当前句，然后进入下一句。

打字阶段默认启用本地音效：正确字符播放轻量机械键音，单词完成播放柔和确认音，错误字符播放短促错误音，整句完成播放成功提示音。底部“音效”按钮可随时关闭或重新开启；视觉上会同步显示单词正确、输入错误和整句完成提示。

页面保留 LangFlow 专注模式的视频、字幕时间线和底部播放控制布局。当前字幕与后续字幕会保持隐藏，完成后才会在右侧显示。

支持上一句、重播本句、下一句、播放速度、字幕面板拖动、进度及错误次数统计。输入阶段按 `Tab` 显示答案并开启单词悬停查词，再按一次隐藏；按 `Ctrl + J` 重播本句，按 `Esc` 退出。

## 安装

1. 打开 Chrome 的 `chrome://extensions/`。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本项目目录。
5. 打开一个带字幕的 YouTube 视频，点击扩展按钮。

修改代码后，在扩展管理页面点击该扩展的“重新加载”即可。

字幕成句逻辑的回归测试可用 `node caption-segmentation.test.js` 运行。

如需只查看界面，可以在项目目录运行 `python3 -m http.server 4173`，然后打开 `http://127.0.0.1:4173/preview.html`。预览页使用演示字幕，不参与扩展运行。

## 隐私与依赖

- 无登录、注册或身份鉴权。
- 无 Supabase、Stripe、会员订阅、自建后端或鉴权。
- 无 npm 依赖和构建步骤。
- 悬停查词时只将当前单词直接发送到夸克查词 API；点击英音或美音时使用与 LangFlow 相同的有道发音地址。不上传整句字幕、输入内容或训练记录。
- 仅在用户点击扩展后读取当前 YouTube 页面及其字幕。

# English Listening Typing

一个基于 YouTube 原声与英文字幕的 Chrome 听写训练扩展。点击 YouTube 播放器右下角的紫色耳机按钮，会在新标签页打开独立学习界面：逐句播放、隐藏答案、接收键盘输入，并在答对后复播原句。

项目使用 Chrome Extension Manifest V3，无需安装依赖、执行构建或部署后端。中文翻译为可选功能，需要使用你自己的 DeepSeek API Key。

![English Listening Typing 独立学习界面](./learning-preview.png)

## 功能特性

- 在 YouTube 播放器设置按钮旁提供紫色耳机入口，与全屏按钮同栏；支持全屏、站内切换及播放器重建。
- 浏览器工具栏扩展图标打开「学习记录」弹窗，展示最近学习的视频、完成句数与上次位置，一键继续。
- 自动在本机保存字幕、当前句、已输入内容、已完成句子、错误次数、速度和音效设置；刷新、关闭学习页或重启浏览器后可继续。
- 新标签页采用左侧视频、右侧字幕与功能、底部全宽听写区的布局。
- 新视频自动读取英文字幕，从当前播放位置所在片段开始；已有学习记录的视频自动续学，已有学习页时直接切回；打开成功后暂停原视频。
- 优先使用人工英文字幕，保留文字分段和原始时间记录；播放时间使用可靠的逐词字幕校准。
- 自动字幕单独处理时间重叠的滚动重复；人工字幕保留真实的重复表达。
- 同组片段全部完成后显示上下文，支持“连起来听”，连听结束仍停留当前片段。
- 自动移除 `[Music]`、`(Laughter)`、`(Applause)` 等非对白提示。
- 直接通过键盘填写字符槽，无需点击输入框；大小写不敏感，标点自动跳过，空格需要输入。
- 输入错误时只清空当前单词，已经完成的单词会保留。
- 答对后收起填空槽与输入提示，显示可悬停查词的完整句子；自动和手动复播均支持可靠词级时间驱动的高亮。
- 句子按词或短语显示彩色下划线，与右侧单句详解的同色块对应。
- 答对后在彩色下划线下方显示连读弧线：依据夸克美式音标与辅音接元音规则生成提示，支持跨颜色分块，换行时不跨行连线。
- 右侧可切换「字幕列表 / 单句详解」，答对后不强制切换；未答对时详解保持锁定。
- 支持答对后停留跟读或自动进入下一句。
- 支持查看答案、单词悬停查词、英美音标与发音。
- 可选 DeepSeek 简体中文翻译，按批预取并在本机缓存 7 天。
- 支持上一句、下一句、重复播放、播放速度、音效、字幕面板拖动和错误次数统计。

## 安装

本项目目前通过 Chrome 开发者模式安装：

1. 下载或克隆本项目。
2. 在 Chrome 地址栏打开 `chrome://extensions/`。
3. 打开页面右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择本项目所在目录。
6. 打开一个带英文字幕的 YouTube 视频，点击播放器右下角的紫色耳机按钮，或浏览器工具栏中的扩展图标。

如果扩展图标没有显示，可以在 Chrome 的扩展菜单中将它固定到工具栏。修改代码后，需要回到 `chrome://extensions/` 点击“重新加载”，再刷新 YouTube 视频页。Edge 也可使用，在 `edge://extensions/` 操作。

升级到 0.12.1 后，请重新加载扩展，再刷新 YouTube 视频页；已经打开的旧学习页请关闭后重开。本版新增 `unlimitedStorage`，用于在本机保留学习字幕和进度，避免多个长视频超出默认存储容量。升级前未保存的答题进度无法追溯恢复。

## 使用方法

1. 打开带英文字幕的 YouTube 视频，将进度移动到想开始训练的位置。
2. 点击播放器设置旁的紫色耳机按钮。首次学习会读取字幕并播放当前句；字幕加载完成前请保持原视频页打开。有记录时会自动接着上次的进度继续。
3. 原句播放结束后，直接输入听到的内容。
4. 答对后，扩展会显示答案和可选中文翻译，并自动复播本句。
5. 默认会停留在当前句，方便反复跟读；按 `Enter` 或 `→` 继续。
6. 点击右上角“返回 YouTube”或按 `Esc`，暂停训练并切回原视频页；学习页会保留，方便继续。

当前句及后续字幕默认隐藏，已经完成的句子才会显示在右侧字幕列表中。

### 学习记录与续学

点击浏览器工具栏里的扩展图标，即可查看学习记录；在任意网页都能点击记录中的「继续学习」，无需先打开原视频。弹窗按最近学习排序，并提供当前 YouTube 视频的学习入口。已全部答对的视频显示「回顾练习」。

进度在输入、切句、完成练习和修改速度时自动保存；学习页左上角会显示保存状态，失败时可点击重试。续学时，未完成的句子会从句首重播，保留已输入的正确内容；已答对的当前句会恢复到跟读状态。

记录仅保存在当前浏览器配置中，不跨设备同步；卸载扩展或清除扩展数据会移除记录。突然断电或强制结束浏览器时，最后一次尚未完成写入的操作可能未保存。

### 快捷键

| 按键 | 作用 |
| --- | --- |
| 直接输入 | 填写当前听写内容 |
| `Backspace` | 删除上一个已接受字符 |
| `Tab` | 显示或隐藏答案；显示后可悬停查词 |
| `Ctrl + J` / `Command + J` | 重播本句 |
| `Enter` / `→` | 答对并停留时进入下一句 |
| `Space` | 非输入阶段播放或暂停；答对并停留时重播 |
| `Esc` | 退出训练 |

## 中文翻译设置

在训练页右侧功能区点击“设置”，可以配置：

- 是否显示简体中文翻译；
- DeepSeek API Key；
- 答对后停留当前句，或自动进入下一句。

翻译固定使用 `deepseek-v4-flash`。扩展每次最多预取 10 个片段，每个片段独立请求翻译（同批最多并发 3 个），并将结果缓存 7 天。片段不完整时，译文也只翻译当前片段，不自动拼入下一条。相比整批一次请求，请求次数会增加。设置页提供“测试连接”按钮，可在保存前验证 API Key。

单句详解共用这个 API Key，与“显示中文翻译”开关独立。配置 Key 后，从开始练习起预加载当前句及后续共最多 10 句的翻译、语义、语法和词组拆解，同时最多请求 3 句；切句后优先准备新的当前句并补充后续内容。每句提供前后各一条字幕作为上下文，答对后才显示详解。只解析当前练习片段，不自动补全句子。结果按原文、上下文和模型缓存 7 天，最多保存 150 条；切换面板和重播会复用解析，失败时可在右侧手动重试。

原句下划线与右侧解释块使用同一份有序拆解数据，重复词按各自位置对应。播放高亮独立使用字幕中可靠的词级时间；缺少或仅有估算时间时，保留完整句子、查词和详解，不模拟逐词高亮。

不配置 API Key 不影响字幕听写、查词与播放；句子拆解和详细解释需要配置 Key。

### 连读提示

练习当前句时会提前查询其中单词的夸克美式音标，答对后显示连读弧线，不需要 DeepSeek API Key。弧线位于原彩色下划线下方，不改变查词与播放高亮；当前句未完成时（包括 Tab 查看答案）不显示。

首版只提示词尾辅音接下一词元音的位置。按音标判断，保留多种读法，只有边界类型一致才标记；支持常见规则复数、所有格、过去式与缩写的音标补全。缺少音标或查询失败的位置跳过，不影响听写；标点、连字符、练习片段边界不跨越。元音滑音、省音和同化暂不标记。弧线是规则预测，不代表已经分析并确认原声实际连读。

音标查询最多同时进行 3 个，相同词共享请求并在本机缓存 7 天，最多保存 2000 个词。只预取当前片段；切句后查询新片段，重播复用缓存。升级后请重新加载扩展，并关闭旧学习页后重新打开。

## 字幕处理方式

扩展会依次尝试从当前播放器和 YouTube 播放器接口获取字幕轨，并优先选择英文人工字幕。字幕进入训练前会经过以下处理：

1. 清理 HTML、声音提示和无效空白；
2. 仅对自动字幕消除时间重叠的滚动重复词；
3. 保留原 cue 作为练习单元，同时保存原文、时间和来源索引；
4. 根据句末标点、长停顿和时长上限建立上下文组，不改变练习边界；
5. 仅合并紧邻的极短残片：一侧不超过 2 词、间隔不超过 350ms、合并后不超过 16 词和 8.5 秒，且不跨句末；
6. 对所有片段（包括已经完整的单句）尝试逐词时间校准：要求至少 90% 规范化词匹配、首尾可靠、时间单调和偏移受限；相邻可靠片段共用边界，不可靠时局部保留原时间。连听上下文同步更新；
7. 一条 cue 含多个句子时，只有每个句子都达到 90% 逐词匹配、首尾边界可靠且时间单调时才拆开；否则保留整条；
8. 连续片段的播放前置不会越过上一片段的结束时间。

人工字幕的显示时间不一定对应发音时间。为校准单句，插件会尝试额外读取同语言自动字幕；没有可用逐词时间时回退到原时间，不能保证音频边界精确。本流程不调用语音识别或大语言模型服务。

新流程不再使用“整句合并后按 14 词重切”，也不将按字数均摊的时间用于新增播放边界。字幕较长、只有整条时间或没有标点时，可能仍保留较长片段。上下文归属是标点与停顿启发式结果，不保证每组恰好对应一个语法完整句。

“连起来听”在当前上下文组的所有片段完成后出现，避免提前暴露后续答案；它不改变答题记录，自动进入下一句模式下也会在连听后停留。语义模型、AI 分句和难度切换留待实际样本对比后评估，本次分句优化不增加模型调用。

设计参考：[asbplayer 的字幕跳转与自动暂停](https://github.com/asbplayer/asbplayer)、[SaT 的边界与长度约束](https://github.com/segment-any-text/wtpsplit)。本次没有引入这些项目的依赖或复制其代码。

答对后的精读界面可通过 [精读预览](http://127.0.0.1:4173/preview.html?scenario=review) 查看，右侧点击「单句详解」。示例解析和逐词时间为演示数据，不代表真实 API 或字幕对齐质量。

浏览器回归测试使用 Playwright 和本机 Chrome：先在 4178 端口启动预览服务，再运行 `node tests/review-browser.cjs`（需在运行环境中提供 Playwright）。覆盖真实键盘输入、答对状态、播放高亮、查词、面板锁定、切句后的延迟响应、失败重试和窄屏布局。

## 权限、网络与隐私

扩展申请以下权限：

- `activeTab`、`scripting`：在用户主动点击扩展后读取当前 YouTube 页面和播放器字幕信息；
- `storage`、`unlimitedStorage`：在本机保存设置、API Key、缓存，以及学习记录和字幕；`storage.session` 暂存学习页的来源信息，关闭学习标签页后清理临时会话，保留学习记录；
- `declarativeNetRequestWithHostAccess`：仅为当前学习标签页的 YouTube 嵌入请求设置扩展来源标识（Referer），避免播放器来源验证错误；关闭标签页后删除会话规则；
- YouTube 域名权限：读取视频和字幕；
- DeepSeek 域名权限：配置 API Key 后，用于已启用的字幕翻译，以及单句详解的提前预加载请求；
- 夸克和有道域名权限：分别用于单词释义和用户主动点击的发音播放。

项目没有登录、注册、分析埋点、自建后端或会员系统。训练输入与错误统计不会上传。启用翻译后，待翻译字幕会发送到 DeepSeek；配置 Key 后，当前及后续预加载字幕（每句带前后各一条上下文）会发送到 DeepSeek 生成详解。为生成连读提示，练习当前片段时，其中未缓存的英文单词及必要的词形原形会自动发送到夸克查询音标；悬停查词时，当前单词也会发送到夸克；点击发音时会请求有道音频。连读提示不上传视频或音频。

API Key 保存在 `chrome.storage.local` 中，不会同步到其他设备，也不会暴露给 YouTube 页面。但它仍属于当前浏览器配置中的本地敏感数据，请不要在共享浏览器配置或不可信设备中保存长期密钥。

## 常见问题

### 点击扩展后没有反应

工具栏图标应打开学习记录弹窗，可在任意网页使用。若仍直接进入旧训练页，请在 `chrome://extensions/` 重新加载扩展。播放器里的学习入口只在 YouTube 视频页出现；如果扩展是在该页面打开后才安装的，请刷新视频页。

### 提示找不到字幕

确认视频确实提供英文字幕，并先在 YouTube 播放器中尝试开启字幕。部分受地区、登录状态或内容限制影响的视频可能无法返回字幕数据。

### 视频没有自动播放

Chrome 可能阻止页面自动播放。点击视频中的播放按钮，或训练页中的“重播本句”继续。

### 答对后没有中文翻译

打开“设置”，确认中文翻译已启用、API Key 已填写，并使用“测试连接”检查网络和密钥状态。翻译失败不会阻止听写继续进行。

### 独立学习页是否无广告

不是。这里嵌入的是正常的 YouTube 播放器，广告仍由 YouTube 决定；扩展不拦截广告。作者禁止嵌入、视频私密或受限制时，学习页会显示相应错误。来源标识遵循 [YouTube 嵌入播放器要求](https://developers.google.com/youtube/terms/required-minimum-functionality)。

## 当前限制

- 仅支持 Chrome Manifest V3 兼容浏览器中的 YouTube 网页版。
- 独立学习页随扩展安装，不需要部署网站。学习记录保存在当前浏览器本地，尚不支持账号同步、导出或跨设备续学。
- YouTube 嵌入播放仍依赖网络；禁止嵌入的视频无法在此学习页播放。
- 训练依赖视频自身提供的英文字幕，字幕质量会影响分句和时间对齐效果。
- YouTube 页面结构或字幕接口变化后，字幕读取逻辑可能需要相应更新。
